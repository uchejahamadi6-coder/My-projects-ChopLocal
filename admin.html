Order desk

One customer basket can become several restaurant sub-orders. Staff see the orders needed for their role; ChopLocal operations coordinates the whole delivery.

Why multiple admins are manageable

Each real staff member should use an individual account. The backend checks their role and restaurant assignment on every request: restaurant staff can only read or update their restaurant’s sub-orders; ChopLocal operations can view all sub-orders and assign riders. Access should be logged, and shared admin passwords should be avoided.

A dropdown in this demo only simulates the screens. Production access control must live in the Node.js API and database rules, never just in the browser UI.
